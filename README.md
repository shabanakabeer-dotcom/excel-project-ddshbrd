# 📊 Digital Literacy Insights – Excel Dashboard

An interactive Excel dashboard that analyses the digital literacy of 1,000 students using pivot tables, pivot charts and slicers.

## 🎯 Objective
To understand how digital literacy and quiz performance change with factors like location, gender, education level, age group, employment and income.

## 📁 Dataset
- **Size:** 1,000 students
- **Factors covered:** location (rural / semi-rural), gender, education level, age group, employment impact, income, feedback, quiz performance

## 🛠️ Tools Used
- **Microsoft Excel** – data cleaning, pivot tables, pivot charts, slicers, dashboard design

## 🗂️ Workbook Sheets
| Sheet | Purpose |
|-------|---------|
| `digital literacy project data` | Raw dataset |
| `pivot data` | Pivot tables used for the charts |
| `Dashboard_project` | Final interactive dashboard |

## 📈 Key Metrics
| Students | Total Literacy | Quiz Performance |
|----------|----------------|------------------|
| 1,000 | 60.2 | 80.3 |

## 📊 Dashboard Contents
- KPI cards: students, total literacy, quiz performance
- Charts by location, gender and education, age group, employment impact, income vs literacy, and feedback
- **Education Level slicer** – click High School, Primary, Secondary, etc. to filter every chart at once
